# Data Dictionary Status (CRS Section 8)

Date: 2026-11-17

This file maps every entity of the CRS data dictionary to what exists in `apps/api/src/Models`, and says what is not built. The entities that are not built belong to later requirements, not to the first two weeks.

| CRS entity           | Status             | In the code                                                                                                                                                                                                                                          |
| -------------------- | ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `User`               | Done               | `User`                                                                                                                                                                                                                                               |
| `GuardianChildLink`  | Done, other models | No separate model. The link is `Family.parentId` (the guardian) with `Child.familyId` (the child). The consent status is `Child.status` plus the latest `ConsentRecord`. The CRS field `relationship` is not stored, because a family has one parent |
| `ChildProfile`       | Done               | `Child` (the age band is worked out from the date of birth)                                                                                                                                                                                          |
| `ConsentRecord`      | Done               | `ConsentRecord` (append-only, with the policy version)                                                                                                                                                                                               |
| `Assessment`         | Done               | `Assessment`                                                                                                                                                                                                                                         |
| `Competency`         | Done               | `Competency`                                                                                                                                                                                                                                         |
| `EvidenceEvent`      | Done               | `EvidenceEvent`, filled automatically from completed activities and assessments                                                                                                                                                                      |
| `GrowthState`        | Done               | `GrowthState`, derived from evidence, readable through `GET /children/:id/growth`                                                                                                                                                                    |
| `ContentItem`        | Done               | `Content` (draft, review and publish states, versions)                                                                                                                                                                                               |
| `StoryMission`       | Done               | `StoryMission`: the link between a story and its mission, with learning outcomes, vocabulary and a decision challenge (see `story-missions.md`). The story asset is the story `Content` itself. The challenge stores no correct answer               |
| `FamilyMission`      | Partly             | `Content` with type `mission`, given to a child through `MissionAssignment`. The instructions and parent prompt fields are not modeled                                                                                                               |
| `QuranAttempt`       | Done               | `QuranAttempt` (PR #85)                                                                                                                                                                                                                              |
| `AIRecitationResult` | Done               | Stored inside `QuranAttempt.result`                                                                                                                                                                                                                  |
| `AuditEvent`         | Done               | `AuditEvent` (append-only, with an admin view and export)                                                                                                                                                                                            |
| `ParentObservation`  | Done               | `ParentObservation` (FR-FAM-002). The note is sensitive free text, limited to 500 characters, never edited                                                                                                                                           |
| `ChildReflection`    | Done               | `ChildReflection` (FR-FAM-003). Fixed choices only, no free text                                                                                                                                                                                     |
| `TeacherReview`      | Not built          | Needed for FR-QUR-006                                                                                                                                                                                                                                |
| `TeacherSession`     | Not built          | Needed for session booking (API-010)                                                                                                                                                                                                                 |
| `RewardEvent`        | Not built          | Needed for FR-GAM-001                                                                                                                                                                                                                                |
| `WeeklyInsight`      | Not built          | Needed for FR-PAR-002. Its inputs are in `parent-intelligence-inputs.md`                                                                                                                                                                             |

Models that are not in the CRS dictionary but exist: `Family`, `Progress`, `TeacherAssignment` and `MissionAssignment` (which mission was given to which child, and until when).

The data layer choices (mongoose and `ObjectId`s instead of the native driver and UUIDs) are recorded in `docs/adr/0009-mongoose-and-objectids-in-the-api.md`.
